### Key Vocabulary
- **Sine Rule**: In any triangle $\triangle ABC$ with sides $a, b, c$ opposite angles $A, B, C$, the ratio of each side length to the sine of its opposite angle is constant: $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$.
- **Ambiguous case of the Sine Rule (SSA)**: When given two sides and a non-included acute angle (SSA), because $\sin(180^\circ - \theta) = \sin\theta$, an unknown angle $\theta$ found via $\sin\theta = k$ may have two valid solutions: an acute angle $\theta_1$ and its supplementary obtuse angle $\theta_2 = 180^\circ - \theta_1$.
- **Cosine Rule**: A generalisation of Pythagoras' theorem to any triangle $\triangle ABC$: $c^2 = a^2 + b^2 - 2ab\cos C$, which rearranges to $\cos C = \frac{a^2 + b^2 - c^2}{2ab}$ when all three sides are known.
- **Included angle**: The angle sandwiched directly between two known sides of a triangle (e.g., angle $C$ is the included angle between sides $a$ and $b$), used in both the Cosine Rule (SAS) and the area formula $A = \frac{1}{2}ab\sin C$.

## Theory & Key Ideas

### The Sine Rule and the Ambiguous Case

By dropping a perpendicular altitude $h$ from vertex $C$ onto side $c$ in any triangle $\triangle ABC$, we observe $h = b\sin A$ and $h = a\sin B$, so $b\sin A = a\sin B$, which divides to give the Sine Rule. Use the Sine Rule whenever you know a matching opposite pair $(a, A)$ plus one other side or angle. When solving for an unknown angle using two sides and a non-included acute angle (SSA), always check whether the supplementary obtuse angle $\theta_2 = 180^\circ - \theta_1$ also fits inside the $180^\circ$ angle sum of the triangle.

$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} \qquad \text{or} \qquad \frac{\sin A}{a} = \frac{\sin B}{b} = \frac{\sin C}{c}$$

> **💡 Put the Unknown in the Numerator**
> Put side lengths on top ($\frac{a}{\sin A} = \frac{b}{\sin B}$) when finding an unknown side; flip the fractions ($\frac{\sin A}{a} = \frac{\sin B}{b}$) when finding an unknown angle.

### The Cosine Rule for SAS and SSS Triangles

When no matching opposite side-angle pair is known, the Sine Rule cannot start. Instead, apply the Cosine Rule in two situations: (1) SAS — two sides and the included angle between them are known ($c^2 = a^2 + b^2 - 2ab\cos C$), or (2) SSS — all three sides are known ($\cos C = \frac{a^2 + b^2 - c^2}{2ab}$). Notice that when $C = 90^\circ$, $\cos 90^\circ = 0$ and the Cosine Rule reduces directly to Pythagoras' theorem $c^2 = a^2 + b^2$; furthermore, if $a^2 + b^2 - c^2 < 0$, then $\cos C < 0$ and the Cosine Rule automatically identifies $C$ as an obtuse angle ($90^\circ < C < 180^\circ$).

$$c^2 = a^2 + b^2 - 2ab\cos C \iff \cos C = \frac{a^2 + b^2 - c^2}{2ab}$$

> **💡 Negative Cosine Means an Obtuse Angle**
> Unlike the Sine Rule, the Cosine Rule is never ambiguous for angles between $0^\circ$ and $180^\circ$: if $\cos C < 0$, your calculator immediately returns the obtuse angle $C > 90^\circ$.

### The Trigonometric Area Formula for Any Triangle

In any triangle $\triangle ABC$ with base $a$ and adjacent side $b$ separated by an included angle $C$, the perpendicular height is $h = b\sin C$. Substituting $h = b\sin C$ into $\text{Area} = \frac{1}{2} \times \text{base} \times \text{height}$ yields $\text{Area} = \frac{1}{2}ab\sin C$. This formula works for both acute and obtuse included angles without needing to construct an altitude.

$$\text{Area} = \frac{1}{2}ab\sin C = \frac{1}{2}bc\sin A = \frac{1}{2}ac\sin B$$

> **💡 Two Sides and the Angle Sandwiched Between Them**
> To use $\text{Area} = \frac{1}{2}ab\sin C$, the two sides $a$ and $b$ MUST meet at the vertex of the known angle $C$.

### WE10_6_2_1: Using the Sine Rule and Resolving the Ambiguous Case

**Problem**: (a) In $\triangle ABC$, $A = 45^\circ$, $B = 60^\circ$, and $a = 10\text{ cm}$. Find the exact length of side $b$. (b) In $\triangle PQR$, $P = 30^\circ$, $p = 6\text{ cm}$, and $q = 6\sqrt{3}\text{ cm}$. Find the two possible values of $\angle Q$ (the acute and obtuse solutions).

| Step | Thinking | Working |
| :---: | :--- | :--- |
| 1 | In part (a), substitute the known opposite pair $(a, A) = (10, 45^\circ)$ and $B = 60^\circ$ into $\frac{b}{\sin B} = \frac{a}{\sin A}$. | $$\frac{b}{\sin 60^\circ} = \frac{10}{\sin 45^\circ} \implies b = \frac{10 \times \frac{\sqrt{3}}{2}}{\frac{\sqrt{2}}{2}} = \frac{10\sqrt{3}}{\sqrt{2}} = 5\sqrt{6}\text{ cm}$$ |
| 2 | In part (b), use $\frac{\sin Q}{q} = \frac{\sin P}{p}$ to evaluate $\sin Q$. | $$\frac{\sin Q}{6\sqrt{3}} = \frac{\sin 30^\circ}{6} \implies \sin Q = 6\sqrt{3} \times \frac{1/2}{6} = \frac{\sqrt{3}}{2}$$ |
| 3 | Since $\sin Q = \frac{\sqrt{3}}{2}$ and $\sin(180^\circ - \theta) = \sin\theta$, check both $Q_1 = 60^\circ$ and $Q_2 = 180^\circ - 60^\circ = 120^\circ$ against $P + Q < 180^\circ$. | $$Q_1 = 60^\circ \quad (P + Q_1 = 90^\circ < 180^\circ \checkmark) \qquad \text{or} \qquad Q_2 = 120^\circ \quad (P + Q_2 = 150^\circ < 180^\circ \checkmark)$$ |

**Answer**: (a) $b = 5\sqrt{6}\text{ cm}$, (b) $Q = 60^\circ$ or $Q = 120^\circ$

### WE10_6_2_2: Using the Cosine Rule to Find an Unknown Side and an Unknown Angle

**Problem**: (a) In $\triangle ABC$, $a = 5\text{ cm}$, $b = 8\text{ cm}$, and the included angle is $C = 60^\circ$. Find the exact length of side $c$. (b) A triangle has side lengths $a = 3\text{ cm}$, $b = 5\text{ cm}$, and $c = 7\text{ cm}$. Find the size of the largest angle $C$.

| Step | Thinking | Working |
| :---: | :--- | :--- |
| 1 | In part (a), substitute $a = 5$, $b = 8$, and $C = 60^\circ$ ($\cos 60^\circ = \frac{1}{2}$) into $c^2 = a^2 + b^2 - 2ab\cos C$. | $$c^2 = 5^2 + 8^2 - 2(5)(8)\cos 60^\circ = 25 + 64 - 80\left(\frac{1}{2}\right) = 89 - 40 = 49 \implies c = 7\text{ cm}$$ |
| 2 | In part (b), the largest angle is opposite the longest side $c = 7\text{ cm}$. Substitute $a = 3, b = 5, c = 7$ into $\cos C = \frac{a^2 + b^2 - c^2}{2ab}$. | $$\cos C = \frac{3^2 + 5^2 - 7^2}{2(3)(5)} = \frac{9 + 25 - 49}{30} = \frac{-15}{30} = -\frac{1}{2}$$ |
| 3 | Since $\cos 60^\circ = \frac{1}{2}$ and $\cos C = -\frac{1}{2}$ is negative, $C$ is the second-quadrant obtuse supplement $180^\circ - 60^\circ = 120^\circ$. | $$C = 180^\circ - 60^\circ = 120^\circ$$ |

**Answer**: (a) $c = 7\text{ cm}$, (b) $C = 120^\circ$

### WE10_6_2_3: Triangle Area Formula and Land Surveying

**Problem**: A triangular paddock in Gippsland has two boundary fences of lengths $a = 120\text{ m}$ and $b = 150\text{ m}$ that meet at an included corner angle of $C = 150^\circ$. Find: (a) the area of the paddock in square metres, and (b) the exact length $c$ of the third boundary fence.

| Step | Thinking | Working |
| :---: | :--- | :--- |
| 1 | Use $\text{Area} = \frac{1}{2}ab\sin C$ with $\sin 150^\circ = \sin(180^\circ - 30^\circ) = \sin 30^\circ = \frac{1}{2}$. | $$\text{Area} = \frac{1}{2}(120)(150)\sin 150^\circ = 9000 \times \frac{1}{2} = 4500\text{ m}^2$$ |

$$c = \sqrt{36\,900 + 18\,000\sqrt{3}}\text{ m} \approx 260.92\text{ m}$$ |

**Answer**: (a) $\text{Area} = 4500\text{ m}^2$, (b) $c = \sqrt{36\,900 + 18\,000\sqrt{3}}\text{ m} \approx 260.92\text{ m}$

## ⚠️ Common Misconceptions Alert

### Subtracting $2ab$ from $a^2 + b^2$ Before Multiplying by $\cos C$ (Order of Operations)
- **The Misconception**: In $c^2 = a^2 + b^2 - 2ab\cos C$, computing $(a^2 + b^2 - 2ab)$ first and then multiplying the entire result by $\cos C$.
- **The Correct Concept**: By order of operations (BIDMAS), $2ab\cos C$ is a single product that must be evaluated before subtracting from $a^2 + b^2$.
- **❌ Incorrect Working**: $$c^2 = (5^2 + 8^2 - 2(5)(8)) \times \cos 60^\circ = (89 - 80) \times 0.5 = 4.5 \quad \text{(Incorrect!)}$$
- **✅ Correct Working**: $$c^2 = (5^2 + 8^2) - (2(5)(8)\cos 60^\circ) = 89 - (80 \times 0.5) = 49 \implies c = 7$$
- **Counter-Example**: When $C = 90^\circ$ ($\cos 90^\circ = 0$), the incorrect method gives $c^2 = (a^2 + b^2 - 2ab) \times 0 = 0$, whereas the true hypotenuse is $\sqrt{a^2 + b^2}$.

### Forgetting the Obtuse Angle Solution in the Sine Rule Ambiguous Case
- **The Misconception**: Assuming that $\arcsin(k)$ on a calculator always gives the only possible angle in a non-right-angled triangle.
- **The Correct Concept**: Because $\sin(180^\circ - \theta) = \sin\theta$, an inverse sine calculation returns only the acute angle $\theta_1 \in (0^\circ, 90^\circ)$. Whenever the side opposite the unknown angle is longer than the side opposite the given acute angle, $180^\circ - \theta_1$ is a second valid obtuse solution.
- **❌ Incorrect Working**: $$\sin\theta = \frac{1}{2} \implies \theta = 30^\circ \text{ only} \quad \text{(Incomplete when obtuse triangle is possible)}$$
- **✅ Correct Working**: $$\sin\theta = \frac{1}{2} \implies \theta = 30^\circ \text{ or } \theta = 180^\circ - 30^\circ = 150^\circ$$
- **Counter-Example**: A triangle with sides $a = 6$, $b = 6\sqrt{3}$ and angle $A = 30^\circ$ can be drawn with either $B = 60^\circ$ (acute) or $B = 120^\circ$ (obtuse).

#### Question `10_6_2_Q1` [Easy] *(Fluency)*
In $\triangle ABC$, $A = 30^\circ$, $B = 45^\circ$, and $b = 12\sqrt{2}\text{ cm}$. Find the length of side $a$.

<details>
<summary><strong>Full Step-by-Step Solution</strong></summary>

1. Apply the Sine Rule: $\frac{a}{\sin 30^\circ} = \frac{12\sqrt{2}}{\sin 45^\circ}$.
2. Substitute $\sin 30^\circ = \frac{1}{2}$ and $\sin 45^\circ = \frac{\sqrt{2}}{2}$: $a = \frac{12\sqrt{2} \times \frac{1}{2}}{\frac{\sqrt{2}}{2}} = 12\text{ cm}$.

**Final Answer**: $12\text{ cm}$
</details>

#### Question `10_6_2_Q2` [Easy] *(Fluency)*
In $\triangle ABC$, $a = 6\text{ cm}$, $b = 10\text{ cm}$, and the included angle is $C = 60^\circ$. Find the exact length of side $c$ using the Cosine Rule.

<details>
<summary><strong>Full Step-by-Step Solution</strong></summary>

1. Substitute $a = 6, b = 10, C = 60^\circ$ into $c^2 = a^2 + b^2 - 2ab\cos C$: $c^2 = 36 + 100 - 2(6)(10)\left(\frac{1}{2}\right) = 136 - 60 = 76$.
2. Take the positive square root: $c = \sqrt{76} = 2\sqrt{19}\text{ cm}$.

**Final Answer**: $\sqrt{76}\text{ cm} = 2\sqrt{19}\text{ cm} \approx 8.72\text{ cm}$
</details>

#### Question `10_6_2_Q3` [Easy] *(Fluency)*
Find the area of $\triangle PQR$ given $p = 16\text{ cm}$, $q = 9\text{ cm}$, and included angle $R = 30^\circ$.

<details>
<summary><strong>Full Step-by-Step Solution</strong></summary>

1. Substitute $p = 16$, $q = 9$, and $R = 30^\circ$ into $\text{Area} = \frac{1}{2}pq\sin R$.
2. Evaluate $\text{Area} = \frac{1}{2} \times 16 \times 9 \times \frac{1}{2} = 36\text{ cm}^2$.

**Final Answer**: $36\text{ cm}^2$
</details>

#### Question `10_6_2_Q4` [Medium] *(Understanding)*
A triangle has side lengths $a = 7\text{ cm}$, $b = 8\text{ cm}$, and $c = 5\text{ cm}$. Use the Cosine Rule to find the exact size of angle $C$ opposite the $5\text{ cm}$ side.

<details>
<summary><strong>Full Step-by-Step Solution</strong></summary>

1. Substitute $a = 7, b = 8, c = 5$ into $\cos C = \frac{a^2 + b^2 - c^2}{2ab} = \frac{49 + 64 - 25}{2(7)(8)} = \frac{88}{112} = \frac{11}{14} \implies C \approx 38.21^\circ$.
2. Note also that for angle $A$ opposite $a = 7\text{ cm}$, $\cos A = \frac{8^2 + 5^2 - 7^2}{2(8)(5)} = \frac{40}{80} = \frac{1}{2} \implies A = 60^\circ$.

**Final Answer**: $C = 38.21^\circ$ (where $\cos C = \frac{11}{14}$); and for angle $A$ opposite $a = 7\text{ cm}$, $A = 60^\circ$
</details>

### Problem-Solving & Modelling

#### Question `10_6_2_Q5` [Medium] *(Bushfire Triangulation)*
Two bushfire spotter towers $A$ and $B$ in the Victorian Alps are $10\text{ km}$ apart along an East-West ridge. A smoke plume $S$ is sighted from $A$ and $B$ such that inside $\triangle ABS$, $\angle SAB = 45^\circ$ and $\angle SBA = 75^\circ$. Find (a) $\angle ASB$, and (b) the exact distance $BS$ from tower $B$ to the smoke plume.

<details>
<summary><strong>Full Step-by-Step Solution</strong></summary>

1. By the angle sum of $\triangle ABS$, $\angle ASB = 180^\circ - (45^\circ + 75^\circ) = 60^\circ$.
2. Apply the Sine Rule: $\frac{BS}{\sin 45^\circ} = \frac{10}{\sin 60^\circ} \implies BS = \frac{10 \times \frac{\sqrt{2}}{2}}{\frac{\sqrt{3}}{2}} = \frac{10\sqrt{2}}{\sqrt{3}} = \frac{10\sqrt{6}}{3}\text{ km}$.

**Final Answer**: (a) $\angle ASB = 60^\circ$, (b) $BS = \frac{10\sqrt{6}}{3}\text{ km} \approx 8.16\text{ km}$
</details>

#### Question `10_6_2_Q6` [Challenging] *(Bearings with the Cosine Rule)*
A yacht leaves Port Phillip Heads ($O$), sails $8\text{ km}$ on a true bearing of $020^\circ\text{T}$ to marker $A$, and then sails $15\text{ km}$ on a true bearing of $140^\circ\text{T}$ to marker $B$. Find (a) the interior angle $\angle OAB$ of $\triangle OAB$, and (b) the straight-line distance $OB$ from Port Phillip Heads to marker $B$.

<details>
<summary><strong>Full Step-by-Step Solution</strong></summary>

1. At marker $A$, the back-bearing to $O$ is $020^\circ + 180^\circ = 200^\circ\text{T}$, while the forward bearing to $B$ is $140^\circ\text{T}$, so the included angle is $\angle OAB = 200^\circ - 140^\circ = 60^\circ$.
2. Apply the Cosine Rule in $\triangle OAB$: $OB^2 = 8^2 + 15^2 - 2(8)(15)\cos 60^\circ = 64 + 225 - 120 = 169 \implies OB = 13\text{ km}$.

**Final Answer**: (a) $\angle OAB = 60^\circ$, (b) $OB = 13\text{ km}$
</details>

#### Question `10_6_2_Q7` [Medium] *(Polygon Mensuration)*
A regular hexagon is inscribed in a circle of radius $r = 6\text{ cm}$ (so it consists of $6$ congruent equilateral triangles of side $6\text{ cm}$ meeting at the centre with central angles of $60^\circ$). Use the triangle area formula to find the exact total area of the regular hexagon.

<details>
<summary><strong>Full Step-by-Step Solution</strong></summary>

1. Each of the $6$ sectors is a triangle with $a = 6\text{ cm}, b = 6\text{ cm}$, and included angle $C = 60^\circ$, so $A_{\text{triangle}} = \frac{1}{2}(6)(6)\sin 60^\circ = 9\sqrt{3}\text{ cm}^2$.
2. Multiply by $6$: $A_{\text{hexagon}} = 6 \times 9\sqrt{3} = 54\sqrt{3}\text{ cm}^2$.

**Final Answer**: $54\sqrt{3}\text{ cm}^2 \approx 93.53\text{ cm}^2$
</details>

#### Question `10_6_2_Q8` [Challenging] *(Combined Area & Cosine Rules)*
An acute-angled triangle has sides $a = 8\text{ cm}$ and $b = 10\text{ cm}$, and its area is $20\sqrt{3}\text{ cm}^2$. Find (a) the size of the acute included angle $C$, and (b) the exact length of the third side $c$.

<details>
<summary><strong>Full Step-by-Step Solution</strong></summary>

1. Use $\frac{1}{2}(8)(10)\sin C = 20\sqrt{3} \implies 40\sin C = 20\sqrt{3} \implies \sin C = \frac{\sqrt{3}}{2}$; since the triangle is acute-angled, $C = 60^\circ$.
2. Apply the Cosine Rule: $c^2 = 8^2 + 10^2 - 2(8)(10)\cos 60^\circ = 64 + 100 - 80 = 84 \implies c = \sqrt{84} = 2\sqrt{21}\text{ cm}$.

**Final Answer**: (a) $C = 60^\circ$, (b) $c = 2\sqrt{21}\text{ cm} = \sqrt{84}\text{ cm}$
</details>

#### Question `10_6_2_Q9` [Challenging] *(Ambiguous Case Analysis)*
In $\triangle ABC$, $A = 30^\circ$, $b = 10\text{ cm}$, and $a = 5\sqrt{2}\text{ cm}$. Show that the ambiguous case of the Sine Rule produces two distinct triangles, and find the difference between the two possible values of $\angle C$.

<details>
<summary><strong>Full Step-by-Step Solution</strong></summary>

1. By the Sine Rule, $\frac{\sin B}{10} = \frac{\sin 30^\circ}{5\sqrt{2}} \implies \sin B = \frac{5}{5\sqrt{2}} = \frac{\sqrt{2}}{2}$, which gives $B_1 = 45^\circ$ or $B_2 = 135^\circ$.
2. Then $C_1 = 180^\circ - (30^\circ + 45^\circ) = 105^\circ$ and $C_2 = 180^\circ - (30^\circ + 135^\circ) = 15^\circ$, so $C_1 - C_2 = 105^\circ - 15^\circ = 90^\circ$.

**Final Answer**: $B_1 = 45^\circ \implies C_1 = 105^\circ$, and $B_2 = 135^\circ \implies C_2 = 15^\circ$; difference $C_1 - C_2 = 90^\circ$
</details>

#### Question `10_6_2_Q10` [Medium] *(Algebraic Classification of Triangles)*
Use the Cosine Rule $\cos C = \frac{a^2 + b^2 - c^2}{2ab}$ to explain why a triangle with side lengths $a, b, c$ (where $c$ is the longest side) is: (i) acute-angled if $a^2 + b^2 > c^2$, (ii) right-angled if $a^2 + b^2 = c^2$, and (iii) obtuse-angled if $a^2 + b^2 < c^2$.

<details>
<summary><strong>Full Step-by-Step Solution</strong></summary>

1. Because side lengths $a, b > 0$, the denominator $2ab$ in $\cos C = \frac{a^2 + b^2 - c^2}{2ab}$ is strictly positive.
2. Thus $\cos C > 0 \iff a^2 + b^2 > c^2$ ($C$ acute), $\cos C = 0 \iff a^2 + b^2 = c^2$ ($C = 90^\circ$), and $\cos C < 0 \iff a^2 + b^2 < c^2$ ($C$ obtuse).

**Final Answer**: Since $2ab > 0$, the sign of $\cos C$ matches the sign of $a^2 + b^2 - c^2$: positive ($0^\circ < C < 90^\circ$), zero ($C = 90^\circ$), or negative ($90^\circ < C < 180^\circ$)
</details>

#### Question `10_6_2_Q11` [Extension] *(Area of a Minor Segment)*
In a circle of radius $R = 9\text{ cm}$, a chord $AB$ subtends a central angle of $\angle AOB = 120^\circ$ at the centre $O$. Find the exact area of the minor segment cut off by chord $AB$ (i.e. sector area minus $\triangle AOB$ area).

<details>
<summary><strong>Full Step-by-Step Solution</strong></summary>

1. The sector area is $A_{\text{sector}} = \frac{120^\circ}{360^\circ}\pi(9)^2 = 27\pi\text{ cm}^2$.
2. The triangle area is $A_{\triangle AOB} = \frac{1}{2}(9)(9)\sin 120^\circ = \frac{81}{2} \times \frac{\sqrt{3}}{2} = \frac{81\sqrt{3}}{4}\text{ cm}^2$, so $A_{\text{segment}} = 27\pi - \frac{81\sqrt{3}}{4}\text{ cm}^2$.

**Final Answer**: $\left(27\pi - \frac{81\sqrt{3}}{4}\right)\text{ cm}^2$
</details>

#### Question `10_6_2_Q12` [Extension] *(Exact Area from Three Sides)*
In $\triangle ABC$, $a = 13\text{ cm}$, $b = 14\text{ cm}$, and $c = 15\text{ cm}$. Use the Cosine Rule to show that $\cos C = \frac{5}{13}$, then use the identity $\sin^2 C + \cos^2 C = 1$ to show that $\sin C = \frac{12}{13}$, and hence find the exact area of $\triangle ABC$.

<details>
<summary><strong>Full Step-by-Step Solution</strong></summary>

1. Calculate $\cos C = \frac{13^2 + 14^2 - 15^2}{2(13)(14)} = \frac{169 + 196 - 225}{364} = \frac{140}{364} = \frac{5}{13}$, and since $C$ is acute, $\sin C = \sqrt{1 - (5/13)^2} = \frac{12}{13}$.
2. Then $\text{Area} = \frac{1}{2}ab\sin C = \frac{1}{2}(13)(14)\left(\frac{12}{13}\right) = 7 \times 12 = 84\text{ cm}^2$.

**Final Answer**: $\text{Area} = 84\text{ cm}^2$
</details>
