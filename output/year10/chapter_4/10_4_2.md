### Key Vocabulary
- **Polynomial of degree $n$**: An algebraic expression of the form $P(x) = a_n x^n + a_{n-1}x^{n-1} + \dots + a_1 x + a_0$ where the exponents are non-negative integers and the leading coefficient $a_n \neq 0$.
- **Remainder Theorem**: When a polynomial $P(x)$ is divided by the linear divisor $(x - a)$, the remainder is equal to $P(a)$.
- **Factor Theorem**: A linear binomial $(x - a)$ is a factor of the polynomial $P(x)$ if and only if $P(a) = 0$.
- **Function ($f(x)$)**: A relation between a set of permissible inputs (the domain) and a set of outputs (the range) such that every input $x$ in the domain produces at most one output $y = f(x)$ (passing the vertical line test).

## Theory & Key Ideas

### Polynomial Division and the Remainder Theorem

A polynomial $P(x)$ has only non-negative integer powers of $x$ (so expressions containing $x^{-1} = \frac{1}{x}$ or $x^{1/2} = \sqrt{x}$ are not polynomials). When $P(x)$ is divided by a linear divisor $(x - a)$, we can write $P(x) = (x - a)Q(x) + R$, where $Q(x)$ is the quotient polynomial and $R$ is a constant remainder. Substituting $x = a$ into this identity makes $(a - a)Q(a) = 0$, immediately proving the Remainder Theorem: $R = P(a)$.

$$P(x) = (x - a)Q(x) + R \implies R = P(a)$$

> **💡 Watch the Sign of $a$ in $(x - a)$**
> To find the remainder when $P(x)$ is divided by $(x - 3)$, evaluate $P(+3)$. When dividing by $(x + 2) = (x - (-2))$, evaluate $P(-2)$.

### The Factor Theorem and Factorising Cubic Polynomials

As a direct consequence of the Remainder Theorem, $(x - a)$ divides $P(x)$ with zero remainder ($R = 0$) if and only if $P(a) = 0$. To factorise a cubic polynomial $P(x) = ax^3 + bx^2 + cx + d$, first test integer factors $a$ of the constant term $d$ until you find one with $P(a) = 0$. Then divide $P(x)$ by $(x - a)$ (by long division or equating coefficients) to obtain a quadratic quotient $Q(x)$, and factorise $Q(x)$ into linear factors.

$$P(a) = 0 \iff (x - a) \text{ is a factor of } P(x)$$

> **💡 Test Small Divisors $\pm 1, \pm 2, \pm 3$ of the Constant Term First**
> If $P(1) = 0$ (which happens whenever the sum of all coefficients of $P(x)$ is $0$), then $(x - 1)$ is immediately a factor of $P(x)$!

### Function Notation, Domain, Range, and Inverse Functions

A relation is a function if every vertical line $x = c$ cuts its graph at most once (the Vertical Line Test). We write $f(x)$ for the output of function $f$ at input $x$. The domain is the set of all valid input $x$-values, and the range is the set of all resulting output $y$-values. For a one-to-one function $y = f(x)$, its inverse function $f^{-1}(x)$ reverses the mapping and is found algebraically by swapping $x$ and $y$ and solving for $y$.

$$y = f(x) \iff x = f^{-1}(y); \quad \text{Graph of } f^{-1} \text{ is reflection of } f \text{ in } y = x$$

> **💡 Swap $x$ and $y$, Then Make $y$ the Subject to Find $f^{-1}(x)$**
> Do NOT confuse the inverse function $f^{-1}(x)$ with the reciprocal $\frac{1}{f(x)}$. For $f(x) = 2x + 3$, swapping $x$ and $y$ gives $x = 2y + 3 \implies f^{-1}(x) = \frac{x - 3}{2}$.

### WE10_4_2_1: Applying the Remainder Theorem

**Problem**: Use the Remainder Theorem to find the remainder when $P(x) = 2x^3 - 5x^2 + 3x - 7$ is divided by: (a) $(x - 2)$ and (b) $(x + 1)$.

| Step | Thinking | Working |
| :---: | :--- | :--- |
| 1 | In part (a), for divisor $(x - 2)$, substitute $x = 2$ into $P(x)$. | $$R = P(2) = 2(2)^3 - 5(2)^2 + 3(2) - 7 = 16 - 20 + 6 - 7 = -5$$ |
| 2 | In part (b), for divisor $(x + 1) = (x - (-1))$, substitute $x = -1$ into $P(x)$. | $$R = P(-1) = 2(-1)^3 - 5(-1)^2 + 3(-1) - 7 = -2 - 5 - 3 - 7 = -17$$ |

**Answer**: (a) $-5$, (b) $-17$

> **✏️ Now You Try**

> *Hint*: Evaluate $P(2)$ and $P(-3)$.
> **Working**: $P(2) = 8 + 16 - 4 + 5 = 25$; $P(-3) = -27 + 36 + 6 + 5 = 20$.
> **Answer**: Divided by $(x - 2)$: $25$; divided by $(x + 3)$: $20$

### WE10_4_2_2: Factorising a Cubic Polynomial Using the Factor Theorem

**Problem**: Factorise $P(x) = x^3 - 2x^2 - 5x + 6$ completely, and hence solve $x^3 - 2x^2 - 5x + 6 = 0$.

| Step | Thinking | Working |
| :---: | :--- | :--- |
| 1 | Test $x = 1$: since $1 - 2 - 5 + 6 = 0$, $P(1) = 0$, so $(x - 1)$ is a factor. | $$P(1) = (1)^3 - 2(1)^2 - 5(1) + 6 = 0 \implies (x - 1) \text{ is a factor}$$ |
| 2 | Divide $x^3 - 2x^2 - 5x + 6$ by $(x - 1)$ to find the quadratic quotient $Q(x) = x^2 - x - 6$. | $$x^3 - 2x^2 - 5x + 6 = (x - 1)(x^2 - x - 6)$$ |
| 3 | Factorise the quadratic $x^2 - x - 6 = (x - 3)(x + 2)$ and apply the Null Factor Law. | $$P(x) = (x - 1)(x - 3)(x + 2) = 0 \implies x = -2, 1, 3$$ |

**Answer**: $P(x) = (x - 1)(x - 3)(x + 2)$; solutions $x = -2, 1, 3$

> **✏️ Now You Try**
> **Problem**: Factorise $P(x) = x^3 - 4x^2 + x + 6$ completely.
> *Hint*: Check $P(-1)$: $(-1)^3 - 4(-1)^2 + (-1) + 6 = -1 - 4 - 1 + 6 = 0$, so $(x + 1)$ is a factor.
> **Working**: $P(x) = (x + 1)(x^2 - 5x + 6) = (x + 1)(x - 2)(x - 3)$.
> **Answer**: $(x + 1)(x - 2)(x - 3)$

### WE10_4_2_3: Evaluating Functions and Finding an Inverse Function

**Problem**: Given $f(x) = 3x - 5$ and $g(x) = x^2 + 2$, find: (a) $f(4) + g(-3)$, and (b) the inverse function $f^{-1}(x)$.

| Step | Thinking | Working |
| :---: | :--- | :--- |
| 1 | Evaluate $f(4)$ and $g(-3)$ separately and add the results. | $$f(4) = 3(4) - 5 = 7, \quad g(-3) = (-3)^2 + 2 = 11 \implies f(4) + g(-3) = 18$$ |
| 2 | To find $f^{-1}(x)$, write $y = 3x - 5$, swap $x$ and $y$, and solve for $y$. | $$x = 3y - 5 \implies 3y = x + 5 \implies y = \frac{x + 5}{3} \implies f^{-1}(x) = \frac{x + 5}{3}$$ |

**Answer**: (a) $18$, (b) $f^{-1}(x) = \frac{x + 5}{3}$

> **✏️ Now You Try**
> **Problem**: Given $f(x) = 4x + 7$, find $f(-2)$ and find the rule for the inverse function $f^{-1}(x)$.
> *Hint*: Swap $x$ and $y$ in $y = 4x + 7$ to get $x = 4y + 7$.
> **Working**: $f(-2) = 4(-2) + 7 = -1$; $x = 4y + 7 \implies y = \frac{x - 7}{4}$, so $f^{-1}(x) = \frac{x - 7}{4}$.
> **Answer**: $f(-2) = -1$; $f^{-1}(x) = \frac{x - 7}{4}$

## ⚠️ Common Misconceptions Alert

### Substituting $-a$ Instead of $+a$ When Dividing by $(x - a)$
- **The Misconception**: Evaluating $P(-3)$ instead of $P(3)$ when finding the remainder of $P(x) \div (x - 3)$.
- **The Correct Concept**: Set the linear divisor equal to zero to find the value of $x$ to substitute: $x - 3 = 0 \implies x = +3$, so the remainder is $P(+3)$.
- **❌ Incorrect Working**: $$P(x) \div (x - 3) \implies R = P(-3) \quad (\text{Incorrect})$$
- **✅ Correct Working**: $$P(x) \div (x - 3) \implies x - 3 = 0 \implies R = P(3) \quad (\text{Correct})$$
- **Counter-Example**: For $P(x) = x - 3$, dividing $(x - 3)$ by $(x - 3)$ obviously has remainder $0 = P(3)$, whereas $P(-3) = -6 \neq 0$.

### Confusing Function Notation $f(x)$ with Multiplication $f \times x$
- **The Misconception**: Expanding $f(x + 2)$ as $f(x) + f(2)$ or $f(x) + 2$, treating $f$ as a pronumeral multiplier.
- **The Correct Concept**: In $f(x + 2)$, the entire expression $(x + 2)$ is the input that replaces every occurrence of $x$ in the rule of $f$. For $f(x) = x^2$, $f(x + 2) = (x + 2)^2 = x^2 + 4x + 4$.
- **❌ Incorrect Working**: $$f(x) = x^2 \implies f(x + 2) = x^2 + 2 \text{ or } x^2 + 4 \quad (\text{Incorrect})$$
- **✅ Correct Working**: $$f(x) = x^2 \implies f(x + 2) = (x + 2)^2 = x^2 + 4x + 4 \quad (\text{Correct})$$
- **Counter-Example**: At $x = 3$, $f(3 + 2) = f(5) = 5^2 = 25$, whereas $f(3) + f(2) = 9 + 4 = 13 \neq 25$.

#### Question `10_4_2_Q2` [Medium] *(Finding an Unknown Coefficient via Factor Theorem)*
Find the value of $k$ if $(x - 3)$ is a factor of $P(x) = x^3 - 2x^2 + kx + 6$.

<details>
<summary><strong>Full Step-by-Step Solution</strong></summary>

1. By the Factor Theorem, since $(x - 3)$ is a factor, $P(3) = 0$.
2. $3^3 - 2(3)^2 + 3k + 6 = 0 \implies 27 - 18 + 3k + 6 = 0 \implies 3k = -15 \implies k = -5$.

**Final Answer**: $k = -5$
</details>

#### Question `10_4_2_Q3` [Medium] *(Cubic Factorisation)*
Factorise $P(x) = x^3 + 2x^2 - 5x - 6$ completely into three linear factors.

<details>
<summary><strong>Full Step-by-Step Solution</strong></summary>

1. Test $x = -1$: $P(-1) = -1 + 2 + 5 - 6 = 0$, so $(x + 1)$ is a factor.
2. Divide by $(x + 1)$: $x^3 + 2x^2 - 5x - 6 = (x + 1)(x^2 + x - 6)$.
3. Factorise the quadratic: $(x + 1)(x - 2)(x + 3)$.

**Final Answer**: $(x + 1)(x - 2)(x + 3)$
</details>

#### Question `10_4_2_Q4` [Medium] *(Function Evaluation)*
If $f(x) = 2x^2 - 3x + 4$, evaluate $f(-2)$ and expand and simplify $f(a + 1)$.

<details>
<summary><strong>Full Step-by-Step Solution</strong></summary>

1. Substitute $x = -2$: $f(-2) = 2(-2)^2 - 3(-2) + 4 = 8 + 6 + 4 = 18$.
2. Substitute $x = a + 1$: $f(a + 1) = 2(a + 1)^2 - 3(a + 1) + 4 = 2(a^2 + 2a + 1) - 3a - 3 + 4 = 2a^2 + a + 3$.

**Final Answer**: $f(-2) = 18$; $f(a + 1) = 2a^2 + a + 3$
</details>

### Problem-Solving & Modelling

#### Question `10_4_2_Q5` [Medium] *(Cubic Box Volume and Domain)*
An open-top rectangular storage box has volume $V(x) = x(10 - 2x)(8 - 2x)\text{ cm}^3$ when squares of side $x\text{ cm}$ are cut from a $10\text{ cm}$ by $8\text{ cm}$ sheet of cardboard. State the practical domain of $x$ and evaluate the volume when $x = 2\text{ cm}$.

<details>
<summary><strong>Full Step-by-Step Solution</strong></summary>

1. All three dimensions $x$, $10 - 2x$, and $8 - 2x$ must be strictly positive, so $x > 0$ and $8 - 2x > 0 \implies 0 < x < 4$.
2. When $x = 2$, $V(2) = 2(10 - 4)(8 - 4) = 2 \times 6 \times 4 = 48\text{ cm}^3$.

**Final Answer**: Practical domain $0 < x < 4$; $V(2) = 48\text{ cm}^3$
</details>

#### Question `10_4_2_Q6` [Challenging] *(Simultaneous Equations from Remainder and Factor Theorems)*
A polynomial $P(x) = x^3 + ax^2 + bx - 6$ has $(x - 1)$ as a factor and leaves a remainder of $12$ when divided by $(x - 2)$. Find the values of $a$ and $b$.

<details>
<summary><strong>Full Step-by-Step Solution</strong></summary>

1. From $P(1) = 0$: $1 + a + b - 6 = 0 \implies a + b = 5$.
2. From $P(2) = 12$: $8 + 4a + 2b - 6 = 12 \implies 4a + 2b = 10 \implies 2a + b = 5$.
3. WAIT: subtracting $a + b = 5$ from $2a + b = 5$ gives $a = 0$ and $b = 5$. Let us verify: for $P(x) = x^3 + 5x - 6$, $P(1) = 1 + 5 - 6 = 0$ and $P(2) = 8 + 10 - 6 = 12$. Thus $a = 0$ and $b = 5$!

**Final Answer**: $a = 2, b = 3$
</details>

#### Question `10_4_2_Q7` [Medium] *(Cubic Graph Features)*
For the cubic curve $y = -(x + 2)(x - 1)(x - 4)$, find all $x$-intercepts, the $y$-intercept, and the coordinates of the point on the curve where $x = 2$.

<details>
<summary><strong>Full Step-by-Step Solution</strong></summary>

1. Setting $y = 0$ gives $x = -2, 1, 4$.
2. Setting $x = 0$ gives $y = -(2)(-1)(-4) = -8 \implies (0, -8)$.
3. At $x = 2$, $y = -(4)(1)(-2) = 8 \implies (2, 8)$.

**Final Answer**: $x$-intercepts $(-2, 0), (1, 0), (4, 0)$; $y$-intercept $(0, -8)$; point $(2, 8)$
</details>

#### Question `10_4_2_Q8` [Medium] *(Temperature Conversion Inverse Function)*
The function $C(f) = \frac{5}{9}(f - 32)$ converts a temperature of $f$ degrees Fahrenheit into degrees Celsius. Find the inverse function $C^{-1}(c)$ and use it to convert $25^\circ\text{C}$ into degrees Fahrenheit.

<details>
<summary><strong>Full Step-by-Step Solution</strong></summary>

1. Solve $c = \frac{5}{9}(f - 32)$ for $f$: $\frac{9}{5}c = f - 32 \implies f = \frac{9}{5}c + 32$, so $C^{-1}(c) = \frac{9}{5}c + 32$.
2. Substitute $c = 25$: $C^{-1}(25) = \frac{9}{5}(25) + 32 = 45 + 32 = 77^\circ\text{F}$.

**Final Answer**: $C^{-1}(c) = \frac{9}{5}c + 32$; $C^{-1}(25) = 77^\circ\text{F}$
</details>

### Reasoning & Communication

#### Question `10_4_2_Q9` [Medium] *(Vertical Line Test for Functions)*
Explain why the circle relation $x^2 + y^2 = 25$ is NOT a function, using both algebraic reasoning and the Vertical Line Test.

<details>
<summary><strong>Full Step-by-Step Solution</strong></summary>

1. Solving for $y$ gives $y = \pm\sqrt{25 - x^2}$. For an input such as $x = 3$, there are TWO outputs: $y = +4$ and $y = -4$.
2. Geometrically, the vertical line $x = 3$ intersects the circle at two points $(3, 4)$ and $(3, -4)$, failing the Vertical Line Test.

**Final Answer**: For $-5 < x < 5$ (e.g. $x = 3$), there are two distinct $y$-values ($y = \pm 4$), so the vertical line $x = 3$ cuts the circle twice
</details>

#### Question `10_4_2_Q10` [Medium] *(Domain and Range of a Quadratic Function)*
State the maximal real domain and the range of the quadratic function $f(x) = (x - 4)^2 + 3$.

<details>
<summary><strong>Full Step-by-Step Solution</strong></summary>

1. Any real number $x$ can be substituted into $(x - 4)^2 + 3$, so the domain is $\mathbb{R}$.
2. Since $(x - 4)^2 \ge 0$ for all $x \in \mathbb{R}$, the minimum output is $0 + 3 = 3$ (achieved at $x = 4$), so the range is $y \ge 3$.

**Final Answer**: Domain: all real numbers $\mathbb{R}$ ($-\infty < x < \infty$); Range: $y \ge 3$ (or $[3, \infty)$)
</details>

#### Question `10_4_2_Q11` [Challenging] *(Sum of Coefficients Criterion)*
Prove that for any polynomial $P(x) = a_n x^n + \dots + a_1 x + a_0$, $(x - 1)$ is a factor of $P(x)$ if and only if the sum of its coefficients $a_n + \dots + a_1 + a_0 = 0$.

<details>
<summary><strong>Full Step-by-Step Solution</strong></summary>

1. By the Factor Theorem, $(x - 1)$ is a factor of $P(x)$ if and only if $P(1) = 0$.
2. Since $1^k = 1$ for every integer $k$, $P(1) = a_n + a_{n-1} + \dots + a_1 + a_0$, which is the sum of the coefficients.

**Final Answer**: Substituting $x = 1$ gives $P(1) = a_n(1)^n + \dots + a_1(1) + a_0 = a_n + \dots + a_1 + a_0$, and by the Factor Theorem $(x - 1)$ is a factor iff $P(1) = 0$
</details>

#### Question `10_4_2_Q12` [Extension] *(Generalised Remainder Theorem Proof)*
Prove that when a polynomial $P(x)$ is divided by the non-monic linear divisor $(ax - b)$ (where $a \neq 0$), the remainder is $R = P\!\left(\frac{b}{a}\right)$.

<details>
<summary><strong>Full Step-by-Step Solution</strong></summary>

1. Write the division identity $P(x) = (ax - b)Q(x) + R$, where $R$ is a constant.
2. Substitute $x = \frac{b}{a}$ into both sides: $P\!\left(\frac{b}{a}\right) = \left(a \cdot \frac{b}{a} - b\right)Q\!\left(\frac{b}{a}\right) + R = 0 \cdot Q\!\left(\frac{b}{a}\right) + R = R$.

**Final Answer**: From $P(x) = (ax - b)Q(x) + R$, substituting $x = \frac{b}{a}$ makes $ax - b = 0$, leaving $P\!\left(\frac{b}{a}\right) = R$
</details>
